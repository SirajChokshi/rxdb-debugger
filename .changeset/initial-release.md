Initial public release of RxDB Debugger.

- `rxdb-debugger`: Full debugger with headless API and mountable UI
- `rxdb-debugger-plugin`: Minimal auto-discovery plugin for the Chrome extension
- `@rxdb-debugger/core`: Low-level headless API
- `@rxdb-debugger/ui`: SolidJS UI components
