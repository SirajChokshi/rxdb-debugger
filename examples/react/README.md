# React example

Music-catalog demo using `rxdb-debugger` / `rxdb-debugger-plugin`.

```bash
# repo root
bun install && bun run build:libs
cd examples/react && bun install && bun run dev
```

Optional encryption: `VITE_RXDB_DEBUGGER_ENABLE_ENCRYPTION=true` and `VITE_RXDB_DEBUGGER_DB_PASSWORD=…`.
